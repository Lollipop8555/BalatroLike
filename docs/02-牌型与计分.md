## 2. 等级与升级曲线

所有牌型初始 **1 级**，等级**无上限**，但仅在本局有效，新开一局重置。
Boss 盲注 `The Arm` 可以永久降低被出牌型的等级（最低 1 级）。

### 计算公式

```
chips(level) = base_chips + (level - 1) × chips_gain
mult(level)  = base_mult  + (level - 1) × mult_gain
```

### 升级来源

| 来源 | 效果 |
| --- | --- |
| 星球牌 | 对应牌型 +1 级 |
| `Black Hole`（幻影） | **所有**牌型 +1 级 |
| `Orbital Tag` | 随机（或指定）牌型 +3 级 |
| `Burnt Joker` | 每回合首手弃掉的牌型 +1 级 |
| `Space Joker` | 每次出牌 **1/4** 概率使该牌型 +1 级 |
| `Telescope` 代金券 | Celestial 包必含你最常打出的牌型的星球牌 |

## 3. 牌型判定规则

### 3.1 优先级

判定按**牌型强度**自上而下匹配，与等级、得分无关：

```
同花五条 > 同花葫芦 > 五条 > 同花顺/皇家同花顺 > 四条 > 葫芦
> 同花 > 顺子 > 三条 > 两对 > 对子 > 高牌
```

- `9♠ 9♠ 9♠ 9♠ 2♠` 判定为**四条**，不会判为同花（四条优先级更高）。
- 出牌顺序不影响判定（`10 A Q K J` 依然是顺子）。

### 3.2 各牌型条件

| 牌型 | 条件 |
| --- | --- |
| 高牌 | 无其他牌型时，取点数最高的一张计分 |
| 对子 | 2 张同点数（花色不限） |
| 两对 | 2 组不同点数的对子 |
| 三条 | 3 张同点数 |
| 顺子 | 5 张连续点数；A 可高（10 J Q K A）可低（A 2 3 4 5），不可环绕（K A 2 3 4 无效） |
| 同花 | 5 张同花色，点数不限 |
| 葫芦 | 3 + 2 同点数组合 |
| 四条 | 4 张同点数 |
| 同花顺 | 同时满足顺子 + 同花 |
| 五条 | 5 张同点数 |
| 同花葫芦 | 葫芦 + 全部同花色 |
| 同花五条 | 5 张同点数且同花色 |

### 3.3 改变判定的关键效果

| 效果 | 影响 |
| --- | --- |
| `Four Fingers` | 同花与顺子可用 **4 张**组成 |
| `Shortcut` | 顺子允许 **1 个点数空档**（如 `10 8 6 5 3`） |
| `Smeared Joker` | ♥/♦ 视为同花色，♠/♣ 视为同花色 |
| `Wild Card`（强化） | 可作为任意花色 |
| `Splash` | **所有**打出的牌都参与计分（不改变牌型判定） |
| `Pareidolia` | 所有牌视为**人头牌** |
| `Stone Card`（强化） | 无点数无花色，`+50 Chips`，可用于凑同花/顺子的“干扰项” |

> `Four Fingers` 与 `Shortcut` 组合可以让极低张数的牌凑出同花顺，是高风险高收益的构筑核心。

## 4. 计分示例

### 示例 A：基础同花

手牌打出 `K♥ Q♥ J♥ 10♥ 9♥`（同花顺 Lv1，无小丑、无强化）

```
基础 Chips = 100
牌面筹码   = 10 + 10 + 10 + 10 + 9 = 49
最终 Chips = 149
最终 Mult  = 8
得分       = 149 × 8 = 1192
```

### 示例 B：加入小丑

同上，持有 `Joker (+4 Mult)`、`Cavendish (×3 Mult)`、`Abstract Joker (每张 Joker +3 Mult)`

```
Chips = 149
Mult  = 8 + 4 + 3（Abstract 自身也计入）= 15
Mult  = 15 × 3 = 45
得分  = 149 × 45 = 6705
```

> 注意：`+Mult` 全部相加后，再被 `×Mult` 连乘，因此**加法小丑放在乘法小丑之前**不影响结果，
> 但 `Blueprint`（复制右侧）与 `Brainstorm`（复制最左）的**位置**会明显改变收益。

### 示例 C：牌型等级提升的边际收益

对子从 1 级升到 5 级：`10×2` → `70×6`。
若手牌 5 张对子牌面合计 25 筹码、无小丑：

```
Lv1: (10 + 25) × 2  = 70
Lv5: (70 + 25) × 6  = 570   // 约 8.1 倍
```

> 这解释了为什么 `Planet` 牌在中期比多买一张小丑更强：**它同时放大 Chips 与 Mult 两个因子**。

## 5. 实现建议

1. **牌型判定**用「点数的计数直方图 + 花色计数」实现，按优先级从高到低匹配，命中即返回。
2. **等级数据**用 `base + (level-1) * gain` 计算，避免维护等级表。
3. **计分管线**拆成 6 个阶段（见 01 文档第 5 节），每个阶段维护 `chips` 与 `mult` 两个变量；
   `×Mult` 必须立即结算到 `mult` 上，不要延后求和。
4. **牌型缓存**：隐藏牌型需在 Run 内记录“是否已打出”，用于解锁 Run Info 与星球牌。
5. **浮点误差**：`×1.5` 连续相乘会出现 `2.25`、`3.375` 等小数；原版显示时**保留一位小数**，
   但内部按浮点计算，最终得分向下取整。
