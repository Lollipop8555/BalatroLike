| 3 | 2,000 | 3,000 | 4,000 | 2,600 | 3,200 |

| 8（Showdown） | 50,000 | 75,000 | 100,000 | 100,000 | 200,000 |

> **Green / Purple Stake 提升的是每个 Ante 的基础值**，小盲与大盲按 ×1.0 / ×1.5 / ×2.0 重新推算。
> `Plasma Deck` 会让**所有**盲注要求再 ×2。

### 无尽模式（Ante 9+）

Ante 9 起改用公式，结果四舍五入到 **2 位有效数字**：

```
要求 = Ante8基础值 × ( 1.6 + 0.75 × (Ante - 8) / (1 + 0.2 × (Ante - 8)) ) ^ (Ante - 8)
```

| Ante | 基础值 |
| ---: | ---: |
| 9 | 110,000 |
| 10 | 560,000 |
| 11 | 7,200,000 |
| 12 | 300,000,000 |
| 13 | 4.7e10 |
| 14 | 2.9e13 |
| 15 | 7.7e16 |
| 16（Showdown） | 8.6e20 |
| 20 | 4.3e43 |
| 30 | 2.1e149 |
| 39 | 4.8e309（超出 double 上限，溢出为 `naneinf`） |

> 增长快于指数（约 `x^(x²)` 量级）。Ante 39 是双精度浮点的硬上限。

### 3.4 价格计算

```
买入价 = round_down( (基础价 + 版本附加费 + 通胀) × 折扣系数 )
卖出价 = floor( 买入价 / 2 )
```

- 结果 ≤ $0 时强制为 **$1**。
- 版本附加费：Foil +$2、Holographic +$3、Polychrome +$5、Negative +$5（消耗牌）。
- 折扣：`Clearance Sale` ×0.75、`Liquidation` ×0.5（**同时压低售价**）。
- `Egg` 每回合自身售价 +$3；`Gift Card` 每回合所有卡售价 +$1。
- `Rental` 贴纸的小丑买入价固定 **$1**，但每回合 **-$3**。

## 四、经济节奏（设计视角）

1. **前期（Ante 1-2）**：收入约 $3+$4+$5 + 剩余出牌 ≈ **$15 ~ $18 / Ante**。
   足够买 2~3 张普通小丑，但不足以同时买代金券。**必须做取舍**。
2. **中期（Ante 3-5）**：利息开始成为主要收入（$5/回合 = $15/Ante）。
   此时「攒到 $25 吃满利息」与「买关键稀有牌」冲突，是核心决策点。
3. **后期（Ante 6-8）**：分数需求指数上升，经济收益被稀释，
   `Bull`、`Bootstraps`、`Rocket` 等**经济转分数**的小丑价值飙升。
4. **利息上限 $5** 是精心设计的锚点：它让「存钱」有上限，
   防止玩家无限滚雪球，同时让 `Seed Money`（$10）成为高价值代金券。
