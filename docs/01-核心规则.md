# 01 核心规则

## 1. 一句话概述

用一副扑克牌，在有限次数的**出牌 / 弃牌**内，把打出的牌型换算成 `Chips × Mult` 的得分，
超过盲注要求即可过关；每通过 3 个盲注推进一个 **Ante**，通过第 8 个 Ante 结算即通关。

游戏本质是**双资源乘法管线**：`Chips` 是加法的“厚度”，`Mult` 是乘法的“倍数”，
两者最后相乘，因此**乘法倍率（×Mult）永远比加法倍率更值钱**。

---

## 2. 基础数值（默认牌组 / White Stake）

| 项目 | 数值 | 说明 |
| --- | --- | --- |
| 起始金钱 | **$4** | 进入 Ante 1 小盲时持有 |
| 手牌上限（Hand Size） | **8** | 每回合抽满至上限 |
| 出牌次数（Hands） | **4** / 回合 | 用完仍未达标的即失败 |
| 弃牌次数（Discards） | **3** / 回合 | 弃掉的牌进入弃牌堆，回合结束重洗 |
| 小丑槽位（Joker Slots） | **5** | 可被 Negative 版本扩充 |
| 消耗品槽位（Consumable Slots） | **2** | 塔罗 / 星球 / 幻影共用 |
| 牌组张数 | **52** | 标准 4 花色 × 13 点数 |
| 每次出牌张数 | **1 ~ 5** | 少于 5 张即按实际张数判定牌型 |

> 牌库耗尽时，弃牌堆会自动洗回抽牌堆，因此不存在“抽干牌库”的风险。

---

## 3. 一局（Run）的结构

```
Run
└── Ante 1..8（之后可进入 Endless 无尽模式）
    └── 每个 Ante 含 3 个 Blind
        ├── Small Blind   要求 = 1.0 × 基础值  奖励 $3
        ├── Big Blind     要求 = 1.5 × 基础值  奖励 $4
        └── Boss Blind    要求 = 2.0 × 基础值  奖励 $5  + 特殊规则
```

- **Small / Big Blind 可以跳过**，跳过后不战而胜、拿不到奖励金钱，但会获得 **1 个 Tag**（见 06 文档）。
- **Boss Blind 不可跳过**，必须击败，否则 Run 结束。
- 击败 Boss Blind 后进入商店，然后进入下一个 Ante。
- 第 8 个 Ante 的 Boss 是 **Showdown Blind**（5 选 1），通过即“通关”（可继续无尽模式）。
- 无限模式下每 8 个 Ante 再出现一次 Showdown Blind（16、24、32…）。

---

## 4. 单个盲注的回合流程

1. **选择盲注**：可选打 Small / Big，或跳过拿 Tag；Boss 必打。
2. **发牌**：从牌库抽至手牌上限。
3. **操作循环**：
   - 选中 1~5 张牌 → **出牌（Play）**：计分，本次得分累加到回合总分；
   - 选中 0~5 张牌 → **弃牌（Discard）**：换牌，不产生分数；
   - 可穿插使用消耗牌（不消耗出牌次数）。
4. **判定**：`回合总分 ≥ 盲注要求` 即通过；出牌次数用尽仍未达标则 Run 结束。
5. **结算（Cash Out）**：获得盲注奖励 + 剩余出牌奖励 + 利息，进入商店。

> 关键设计点：**弃牌是“提高单次出牌质量”的资源**，出牌次数是“尝试次数”。
> 多数构筑的胜负在于如何把有限的出牌次数转化为一次爆发。

---

## 5. 计分公式

```
单次出牌得分 = 最终 Chips × 最终 Mult
```

其中：

```
最终 Chips = 牌型基础 Chips
           + Σ 每张计分牌的点数筹码
           + 各来源的 +Chips（卡牌强化、版本、小丑、星球等级…）

最终 Mult  = 牌型基础 Mult
           + 各来源的 +Mult
           × 各来源的 ×Mult（连乘）
```

- **点数筹码**：2~10 按面值，J/Q/K = **10**，A = **11**。
- **加法与乘法的顺序不影响结果**，但 ×Mult 之间是连乘，所以 `×3` 的小丑远比 `+30 Mult` 强。
- 牌型等级提升会同时增加基础 Chips 与基础 Mult（见 02 文档）。

### 计分顺序（实现参考）

原版严格按以下阶段执行，顺序会影响 `Hanging Chad`、`Photograph`、`Blueprint` 等牌的收益：

1. **确定牌型**与参与计分的牌（默认只有构成牌型的牌计分，`Splash` 可打破此规则）。
2. **应用牌型基础值**（含等级加成）。
3. **逐张结算计分牌**（从左到右）：
   a. 加牌面点数筹码；
   b. 触发该牌的**强化**（Bonus / Mult / Glass / Stone / Lucky / Steel 视位置）；
   c. 触发该牌的**版本**（Foil `+50`、Holo `+10`、Poly `×1.5`）；
   d. 触发**蜡封**（红印重触发整张牌）；
   e. 触发所有“**该牌计分时**”的小丑效果（小丑从左到右）。
4. **手牌中效果**：`Steel`（×1.5）、`Gold`（+$3）等仅在“留在手中”时生效。
5. **独立小丑效果**：所有不依赖具体牌的小丑，按**从左到右**依次触发。
6. **相乘**得到本次得分，累加到回合总分。

> 因此**小丑的排列顺序是有意义的**：`Blueprint` 复制右侧、`Brainstorm` 复制最左侧，
> 加法小丑应放在乘法小丑左侧以获得更高收益（`+` 先算，`×` 后算）。

## 6. 经济系统

### 6.1 收入来源

| 来源 | 金额 |
| --- | --- |
| 击败 Small Blind | **$3**（Red Stake 起为 **$0**） |
| 击败 Big Blind | **$4** |
| 击败 Boss Blind | **$5** |
| 剩余出牌次数 | 每次 **$1** |
| 利息 | 每持有 **$5** 得 **$1**，**上限 $5**（即 $25 封顶） |
| 小丑 / 卡牌效果 | 各异（Golden Joker、Gold Card 等） |

- 利息在**回合结算时**按当前金钱计算；回合结束才触发的收入（如 Golden Joker）**不计入当回合利息**。
- `Seed Money` 把利息上限提到 **$10**，`Money Tree` 提到 **$20**，`To the Moon` 每 $5 额外 +$1。
- 绿色牌组 **完全不获得利息**，改为每剩余出牌 $2、每剩余弃牌 $1。

### 6.2 支出

| 项目 | 价格 |
| --- | --- |
| 普通小丑 | $1 ~ $6 |
| 罕见小丑 | $4 ~ $8 |
| 稀有小丑 | $7 ~ $10 |
| 传奇小丑 | $20（无法购买，仅 The Soul 生成） |
| 塔罗 / 星球 | $3 |
| 幻影 | $4 |
| 扑克牌 | $1 |
| 代金券 | $10 |
| 补充包 | $4 / $6 / $8（Normal / Jumbo / Mega） |
| 商店重掷 | 首次 **$5**，每次 **+$1**，进入新商店重置 |

### 6.3 买卖规则

```
买入价 = (基础价 + 版本附加费) × 折扣系数   // 向下取整到整数
卖出价 = floor(买入价 / 2)                 // 最低 $1
```

- 版本附加费：Foil `+$2`、Holographic `+$3`、Polychrome `+$5`、Negative `+$5`。
- 折扣：`Clearance Sale` ×0.75，`Liquidation` ×0.5（同时压低小丑售价）。
- `Egg` 每回合结束使自身售价 +$3；`Gift Card` 每回合使所有小丑/消耗牌售价 +$1。

## 7. 商店

每回合结算后进入商店，固定包含：

| 槽位 | 数量 | 内容 |
| --- | --- | --- |
| 随机卡牌 | **2** | 小丑为主，少量塔罗/星球（`Magic Trick` 后可出扑克牌） |
| 补充包 | **2** | 每轮首个商店必有 1 个普通 **Buffoon Pack** |
| 代金券 | **1** | 仅击败 Boss 后刷新 |

- 卡牌类型权重：小丑 **20**、塔罗 **4**、星球 **4**（约 71.4% / 14.3% / 14.3%）。
- 小丑稀有度：普通 **70%**、罕见 **25%**、稀有 **5%**。
- 重掷**只刷新 2 个随机卡牌槽**，不刷新补充包与代金券。

## 8. 补充包

| 类型 | 内容 | Normal $4 | Jumbo $6 | Mega $8 |
| --- | --- | --- | --- | --- |
| Arcana | 塔罗牌 | 3 选 1 | 5 选 1 | 5 选 2 |
| Celestial | 星球牌 | 3 选 1 | 5 选 1 | 5 选 2 |
| Standard | 扑克牌 | 3 选 1 | 5 选 1 | 5 选 2 |
| Buffoon | 小丑牌 | 2 选 1 | 4 选 1 | 4 选 2 |
| Spectral | 幻影牌 | 2 选 1 | 4 选 1 | 4 选 2 |

- 塔罗 / 星球 / 幻影包选中后**立即使用**，不占消耗品槽。
- 打开塔罗/幻影包时会额外发一手等同手牌上限的牌供其作用。
- 跳过补充包会让 `Red Card` 获得 `+3 Mult`。

## 9. 消耗牌

| 类型 | 数量 | 作用 |
| --- | --- | --- |
| 塔罗（Tarot） | 22 | 强化牌、变形、给钱、生成小丑 |
| 星球（Planet） | 12 | 永久提升某种牌型等级（本局内） |
| 幻影（Spectral） | 18 | 高强度一次性效果，常伴随代价 |

- 三者共用**消耗品槽位**（默认 2 个）。
- 塔罗/星球售价 $3，幻影 $4；带 Negative 的消耗牌 +1 槽位。
- 已拥有的消耗牌不会重复出现，除非持有 `Showman`。

## 10. 本局内 vs 永久

| 数据 | 作用范围 |
| --- | --- |
| 牌型等级 | **本局（Run）**，新开一局重置为 1 级 |
| 小丑牌 | 本局持有，Run 结束消失 |
| 扑克牌强化 / 版本 / 蜡封 | 本局内永久（除非被摧毁） |
| 牌组（Deck） | 永久，跨 Run |
| 代金券 | 本局内永久 |
| 收藏解锁进度 | 账号级永久 |

## 11. 术语表

| 术语 | 含义 |
| --- | --- |
| Ante | 底注，一组 3 个盲注，决定分数要求 |
| Blind | 盲注，本回合要击败的“关卡” |
| Chips | 筹码，加法项 |
| Mult | 倍率，乘法项 |
| Debuff | 减益，被标记的牌/小丑效果失效 |
| Retrigger | 重触发，让一张牌的能力再结算一次 |
| Edition | 版本，Foil / Holographic / Polychrome / Negative |
| Enhancement | 强化，卡牌本身的附加效果 |
| Seal | 蜡封，红/蓝/紫/金四种 |
| Tag | 标签，跳过盲注获得的奖励 |
| Voucher | 代金券，永久（本局内）强化系统 |
| Stake | 难度等级，White → Gold |
